GUI Tutorial

Navigation

Open the GUI with your bind, then use the search bar to filter modules instantly. The top-right buttons switch between the classic multi-panel layout and the unified panel layout.

Modules

  • Left click toggles a module.
  • Right click opens the module settings.
  • Modules that are faded out are blocked by the current AntiCheat profile.

Settings

  • Sliders can be dragged and also scrolled over in the browser panel.
  • Enum settings cycle when you click them.
  • Keybinds listen for the next key press, and the small X button unbinds them.

Panel Mode

Pick a category on the left, click a module in the middle to toggle it, and right click that module to load its settings on the right side.

AntiCheat Profiles

The Config category contains the AntiCheat selector. Switching between Vanilla, Grim and Vulcan can automatically disable blocked modules and tune a few safer default timings.

Scrolling

All long settings lists and this tutorial are scrollable. If you use the embedded browser zoom, hold Ctrl and use the mouse wheel.
